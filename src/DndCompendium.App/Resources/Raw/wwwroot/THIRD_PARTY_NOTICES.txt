Security substitution
---------------------

The npm dependency graph of marked-variables contains expr-eval 2.0.2. Its
implementation is NOT shipped in the mobile bundle. The build aliases it to
renderer/safe-expr-eval.js, an original arithmetic-only compatibility layer,
because expr-eval has unresolved code-execution advisories.
